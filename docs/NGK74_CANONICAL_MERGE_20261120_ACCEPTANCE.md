## สิ่งที่แก้ไข

1. เพิ่ม `nongkum-canonical-74.json` เป็นบัญชี 64 รายการที่รวมโรงเรียนอย่างไม่ซ้ำ บันทึกรหัสแถวต้นทาง ชื่อกิจกรรมก่อนปรับรูปแบบ สถานะจากแหล่ง และจำนวนโรงเรียน
2. เพิ่มส่วนตรวจสอบการรวมรายการใน `nongkum.html` เพื่อให้ผู้ใช้ดูได้ว่ารวมคู่ใดและได้โรงเรียนกี่แห่ง พร้อมลิงก์บัญชี JSON
3. เพิ่ม `tests/ngk74-canonical-source-20261120.test.cjs` ตรวจว่าบัญชีรวมสอดคล้องกับข้อมูลต้นทางครบทั้ง 67 แถว รวมถึง 8 โรงเรียน และ 34 รายการแข่งขันหลายโรงเรียน
4. **คงแถวต้นทางทั้ง 67 แถว** เพื่อให้การอ้างอิงรหัสเกณฑ์ครั้งที่ 74, ประวัติการปรับแก้ของโรงเรียน และชุดทดสอบเดิมยังตรวจย้อนหลังได้ การแสดงผลผ่าน `canonicalRows` ยังคงเป็น 64 รายการโดยไม่แสดงซ้ำ

ข้อมูลนี้อ้างอิงเพื่อเตรียมแข่งขันเท่านั้น ไม่เปลี่ยนรายการเปิดสมัครหรือผลการแข่งขัน ไม่แก้ตารางฐานข้อมูลหรือ API ของระบบหลัก `/74/` และไม่ถือเป็นการแต่งตั้งกรรมการหรือการอนุมัติสนาม
