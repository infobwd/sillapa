# เครดิตผู้พัฒนาเว็บไซต์แบบสุภาพ — Design & Acceptance

**โครงการ:** Sillapa 74 (ระบบสารสนเทศเพื่อเตรียมจัดการแข่งขัน สพป.กาญจนบุรี เขต 4)  
**Baseline:** `main` commit `fe8132f6eb1e5388994894714ef6a09176d47fdd` (PR #12 merged)  
**Branch:** `feat/quiet-developer-attribution`  
**สถานะ:** รอตรวจรับ Local-First และอนุมัติ Merge; ไม่แก้ข้อมูลแข่งขันหรือระบบสมัคร

## หลักการออกแบบ

ผู้บริหาร ครู และผู้จัดควรตรวจสอบได้ว่า **ใครพัฒนาเว็บไซต์** โดยไม่ทำให้เครดิตเป็นหัวเรื่องใหญ่หรือสื่อว่าได้รับการรับรองให้เป็นเว็บสมัครแข่งขันอย่างเป็นทางการ

**ข้อความผู้พัฒนา (Public):**  
> พัฒนาเว็บแอปโดย **นายนพรุจ ลับบัวงาม** · ผู้อำนวยการโรงเรียนบ้านวังด้ง

## จุดที่วางเครดิต

1. **หน้าแรก `#overview`:** เพิ่มบรรทัดตัวเล็ก สีรอง **ใต้คำอธิบายแหล่งข้อมูลปัจจุบัน** เพื่อให้ผู้บริหารเห็นชื่อผู้พัฒนาเมื่อเข้าเว็บไซต์ โดยไม่แทรกชื่อใน Hero title, KPI, splash/loading หรือรายการแข่งขัน
2. **ส่วนท้ายเว็บไซต์ทุกหน้า:** แยกแถวเครดิตออกจากรายชื่อแหล่งข้อมูลย้อนหลัง โดยใช้ตัวอักษรขนาดพออ่านได้ ไม่มีตราบุคคล รูปผู้พัฒนา คำยกย่อง หรือสีพิเศษ
3. **“เกี่ยวกับเว็บไซต์นี้”:** ใช้ `<details><summary>` ของ HTML ที่กด/ใช้คีย์บอร์ดเปิดปิดได้ ไม่ต้องมี JavaScript หรือ Modal ใหม่ เนื้อหาบอกวัตถุประสงค์และข้อจำกัดของเว็บไซต์
4. คงปุ่ม **ติดตั้งเป็นแอป** และ **ประกาศการใช้ข้อมูลส่วนบุคคล (PDPA)** ใน Footer รวมถึงแหล่งอ้างอิงย้อนหลังเดิมครบถ้วน

## ข้อความจำกัดขอบเขตที่ห้ามหาย

> เป็นเครื่องมือประกอบการวางแผน **ไม่ใช่เว็บไซต์ลงทะเบียนสมัครแข่งขันหรือรายงานผลการแข่งขัน** และไม่ใช้แทนประกาศอย่างเป็นทางการของผู้จัด

แหล่งข้อมูลการแข่งขันย้อนหลังครั้งที่ 70 และ 73 ยังต้องระบุที่มาตามเดิม ไม่ถือเป็นผลงานข้อมูลของผู้พัฒนาเว็บไซต์ ไม่มีการเปลี่ยน `AcademicCompetitionManager` หรือ Production ครั้งที่ 73

## Acceptance Criteria

- [ ] หน้าจอมือถือ/คอมพิวเตอร์อ่านบรรทัดเครดิตใต้ข้อมูลที่มาในหน้าแรกได้ ไม่บังปุ่มหรือ KPI; Dark/Light theme ใช้สีรองอ่านได้
- [ ] ท้ายเว็บไซต์ทุกหน้ามีชื่อและตำแหน่งผู้พัฒนาถูกต้อง ไม่แสดงเครดิตเป็นตรารับรองของสำนักงานเขต
- [ ] เปิด/ปิด “เกี่ยวกับเว็บไซต์นี้” ได้บน iPhone/iPad/Chrome และด้วยคีย์บอร์ด; ไม่เพิ่ม Modal หรือเส้นทางใหม่
- [ ] แหล่งข้อมูล การติดตั้ง PWA และประกาศ PDPA ใช้งานได้เหมือนเดิม
- [ ] ไม่มีการแก้ระบบสมัคร ผลแข่งขัน จำนวน KPI หรือข้อมูลส่วนบุคคลของนักเรียน/ครู/กรรมการ
- [ ] PWA Service Worker เป็น `sillapa-public-v10-ia6-20261015` เพื่อหลีกเลี่ยงหน้าเว็บรุ่นก่อนติดแคช
