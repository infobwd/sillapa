# NG74-TEACHER-NAV-02 — ทะเบียนครูและขั้นตอนอนุมัติการเผยแพร่

## เป้าหมายและเกณฑ์ตรวจรับ
- หน้าสารสนเทศกลุ่ม `nongkum.html` มีลิงก์แยกไปยังหน้า **ดูทะเบียนครูและความคืบหน้า** และ **โรงเรียนตรวจสอบรายชื่อครู** ใช้งานบนมือถือได้
- `teacher-directory.html` ใช้ Google Sans และ Noto Sans Thai เช่นหน้าเดิม พร้อม fallback และไม่บังคับดาวน์โหลดฟอนต์จึงอ่านได้เมื่อออฟไลน์
- แสดงสรุปจำนวนจาก snapshot ณ 4 พ.ย. 2569; ห้ามแสดงชื่อครูที่ยังไม่ผ่านอนุมัติ
- ไม่เปลี่ยน Google Sheets หรือฐานข้อมูลจริง; ไม่ใช้ GitHub Actions

## ขั้นตอนก่อนเผยแพร่ชื่อครูจริง
1. โรงเรียนตรวจชื่อ สถานะปัจจุบัน วิชาเอก และวิชาที่สอนใน Google Sheets; `ตรวจครบ` ไม่ได้แปลว่าอนุมัติเผยแพร่
2. ผู้ควบคุมข้อมูล/ผู้รับผิดชอบงานกำหนดและบันทึกฐานกฎหมาย วัตถุประสงค์ ข้อความแจ้งข้อมูล ช่องทางติดต่อ ระยะเวลาเผยแพร่ และวิธีรับคำขอแก้ไข/คัดค้าน โดยพิจารณา PDPA
3. ผู้มีอำนาจของโรงเรียนหรือผู้จัดอนุมัติการเผยแพร่รายชื่อที่จำเป็นเป็นรายคนหรือชุด พร้อมบันทึกหลักฐานไว้ในพื้นที่จำกัดสิทธิ์ **ไม่ใช่ Public Repository**
4. สร้างรายการส่งออกเฉพาะ `name, school, major, subject` สำหรับคนที่ (ก) ตรวจครบ (ข) ยืนยันยังอยู่โรงเรียน (ค) อนุมัติให้เผยแพร่; ไม่ส่งออกสถานะย้าย/ออก รหัสครูกลางหรือข้อมูลติดต่อ
5. ตรวจข้อมูลซ้ำและให้ผู้รับผิดชอบตรวจรับ preview ก่อนเปิด PR แยก; ตรวจความขัดแย้งกับ main, ทดสอบมือถือ/คีย์บอร์ด/ค้นหา/ภาษาไทย และ Merge เมื่อผ่านเกณฑ์
6. เมื่อตรวจพบการถอนอนุมัติหรือแก้ไขสถานะ ต้องนำชื่อออกจากแหล่งสาธารณะโดยเร็วและพิจารณาผลของแคช GitHub Pages; ห้ามอ้างว่า noindex ทำให้เป็นข้อมูลส่วนตัว

## ข้อจำกัด
GitHub Pages เป็นสาธารณะ; ไม่ควรเก็บหลักฐานอนุมัติหรือข้อมูลส่วนบุคคลที่ไม่จำเป็นใน Git history. การแจ้งเตือนอัตโนมัติไม่ใช่การอนุมัติเผยแพร่. หน้าเว็บใช้ snapshot ไม่ใช่การอ่าน Google Sheets แบบเรียลไทม์.
