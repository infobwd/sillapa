## แหล่งข้อมูลและระดับความเชื่อมั่น
ผู้จัดงานระบุว่า [โฟลเดอร์ Google Drive เกณฑ์ครั้งที่ 74](https://drive.google.com/drive/folders/1x3oxZyV817SbGyFmX8L7tZQEwJ75gzMH) ได้รับการยืนยันจากสำนักงานเขตแล้ว ผู้ช่วยตรวจรายชื่อไฟล์/ข้อมูล PDF ในโฟลเดอร์และไฟล์ที่อยู่ในบริบทโครงการ แต่อย่าแปลความเป็นการตรวจสอบประกาศทางการจากเว็บไซต์สำนักงานเขตโดยอิสระ

- [บัญชีรายการแข่งขันครั้งที่ 74 ปีการศึกษา 2569](https://drive.google.com/file/d/1ZX58b67IeQjNziOr-NtKgRrMd7xhOWUQ/view?usp=drivesdk): 3 หน้า / 56 กิจกรรมหลัก ตามเนื้อหาใน PDF
- PDF เกณฑ์แยก 17 หมวด (รวม 17 ไฟล์): ภาษาไทย, คณิตศาสตร์, วิทยาศาสตร์, สังคมศึกษา, ภาษาต่างประเทศ, ภาพยนตร์สั้น, คอมพิวเตอร์, การงานอาชีพ, สุขศึกษา, ทัศนศิลป์, นาฏศิลป์, ดนตรี, หนังสือเล่มเล็ก, ปฐมวัย, นักบินน้อย, พัฒนาผู้เรียน, โรงเรียนเรียนรวม
- โฟลเดอร์ย่อย “เกณฑ์การแข่งขันที่ใช้อ้างอิง” มีข้อมูลครั้งที่ 70/72/73; ไม่ใช้เป็นเกณฑ์หลักครั้งที่ 74
- Google Drive รายงานว่าไฟล์มีการแชร์ (`shared=true`) แต่ **ไม่ได้คืน permission metadata พอยืนยันว่าเข้าได้โดยไม่ล็อกอิน** ต้องทดสอบลิงก์ใน Private/Incognito โดยบุคคลภายนอกก่อนถือว่าพร้อมใช้สาธารณะ

## หลักการจับคู่ (ไม่จับแบบ fuzzy)
1. อ้างอิงชื่อและระดับชั้นจาก PDF ตารางหน้าต้นของแต่ละหมวด และรายละเอียดในหน้าถัดไปเฉพาะกรณีที่ต้องตรวจชี้แจง
2. ตรวจ **ลำดับแถว + ชื่อกิจกรรมตรงกับ snapshot + ระดับชั้นตรง snapshot** ทุกครั้งก่อนคืนลิงก์ PDF 74; หากข้อมูลเว็บเปลี่ยนโดยไม่ได้ทบทวน mapping จะแสดง “รอตรวจสอบ” อัตโนมัติ
3. ใช้ URL จริงของไฟล์ PDF หมวดที่มีเกณฑ์ ไม่ใช้แค่โฟลเดอร์รวมหรือบัญชีรายการรวมเป็นแทนเกณฑ์
4. เกณฑ์ครั้งที่ 70 เป็น `details` ลิงก์ย้อนหลังรอง ไม่แสดงเป็นเกณฑ์ครั้งที่ 74
5. ไม่แก้ตารางการแข่งขัน บุคคล โรงเรียน ข้อมูลย้อนหลัง และฐานข้อมูล Production
6. ชุดข้อมูลในเว็บปัจจุบันมี 63 แถวระดับกิจกรรม/ระดับชั้น (มีบางชื่อซ้ำจากรายการของหลายโรงเรียน) จึงไม่ใช่ยอดกิจกรรมหลัก 56 รายการใน PDF สรุป

- `round74-criteria-sources.js`: บัญชีลิงก์ PDF 17 หมวด + mapping 57 รายการ + review reasons 6 รายการ + guard เมื่อชื่อ/ระดับชั้นเปลี่ยน
- `nongkum.html`: สคริปต์อ้างอิงโหลดก่อนหน้าเกณฑ์, เปลี่ยนกล่องเกณฑ์ในตารางเป็น PDF 74 ก่อน พร้อม historical 70 แบบยุบ; หน้าเกณฑ์มีตัวกรอง “ทั้งหมด / มี PDF 74 / ต้องตรวจสอบ / มีทะเบียนย้อนหลัง 70” และแสดง PDF ตามรายการ พร้อมห้องสมุด PDF 17 หมวดแบบยุบ

## Acceptance criteria และการทดสอบที่ต้องทำ
1. เปิดหน้า `nongkum.html#criteria` บน iPhone/Android/Desktop แล้วตรวจชื่อกิจกรรม ระดับชั้น และสถานะ PDF 74 ตามแถว
2. ทดสอบตัวกรองทั้งหมด / มีเกณฑ์ 74 / รอตรวจสอบ / ย้อนหลัง 70, การค้นหา และปุ่มเปิด PDF 74 ให้ตรงหมวด
3. ตรวจ 6 รายการผิดปกติว่ามีคำเตือนชัด ไม่อ้างว่าเอกสาร PDF 74 ใช้ได้โดยตรง
