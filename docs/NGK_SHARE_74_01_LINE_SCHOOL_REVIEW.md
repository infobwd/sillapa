# NGK-SHARE-74-01 — แชร์บัญชีรายการแข่งขันของโรงเรียนผ่าน LINE

วันที่ 6 พฤศจิกายน 2569 · Repository `infobwd/sillapa` · Branch `ngk-share-74-01-school-line-20261106`

## วัตถุประสงค์และขอบเขต
ให้แต่ละโรงเรียนเปิดบัญชีรายการแข่งขันของตนและแชร์ลิงก์ผ่าน LINE เพื่อให้ผู้บริหาร/ครูตรวจว่า **รายการขาด เกิน หรือระดับชั้นไม่ตรง** โดยไม่ต้องสมัครสมาชิกหรือบันทึกการกดยืนยัน

**ไม่ทำ:** ระบบรับสมัคร, ผลแข่งขัน, การบันทึกการยืนยันหรือคำรับรอง, Backend/DB, การแก้ทะเบียนจริง, การเผยแพร่ข้อมูลนักเรียนหรือครู, GitHub Actions

## แหล่งข้อมูล/สถานะก่อนเริ่ม
- `main` ของ `infobwd/sillapa`: `nongkum.html` มีตัวเลือก `#audit-school`, ตาราง `#complete-field-plan .venue-table`, `#school-export`, การพิมพ์/CSV และกรองข้อมูลครบอยู่แล้ว
- `nongkum-schools.js`: รายชื่อโรงเรียนและ `school_id` ที่เผยแพร่ได้ 8 โรงเรียน; ต้องใช้ ID ใน URL ไม่อ้างอิงลำดับ option
- `nongkum-mobile-ux.js`: โหลดท้ายหน้า `nongkum.html`; เพิ่มตัวเชื่อมส่วนแชร์ได้โดยไม่แก้ `nongkum.html`
- `nongkum-sports-hub/js/shared.js`: แนวคิดแชร์ข้อความ/ลิงก์รายรายการและคัดลอกสำรอง; งานนี้แชร์ **ทั้งโรงเรียน** ไม่ใช่รายการเดียว
- README ฉบับ 6 พ.ย. 2569 ระบุว่าตารางปัจจุบันมี 62 แถว จับคู่เกณฑ์ 74 ได้ 51 แถว/รอตรวจ 11 แถว จึงห้ามตีความว่าเป็นรายการรับสมัครที่ยืนยันแล้ว
- PR ที่เปิดขณะวางแผน: #127 แตะ `nongkum.html` และ `README.md`, #140 แตะ `round74-confirmed-groups.js`, #122 เป็น docs ทะเบียนครู, #70 แตะ 3D; งานนี้หลีกเลี่ยงไฟล์ดังกล่าว

## การออกแบบ
1. เพิ่มปุ่ม “แชร์ผ่าน LINE” และ “คัดลอกลิงก์” ในกล่องส่งออกเดิม เฉพาะเมื่อเลือกโรงเรียน; ไม่สร้างหน้าใหม่
2. URL แบบ `nongkum.html?school=71020019#list`; query รับเฉพาะ `school_id` ที่พบจริงใน registry (ไม่รับชื่ออิสระ และไม่แก้ไขข้อมูลเมื่อพารามิเตอร์ผิด)
3. เมื่อเปิดลิงก์ผ่าน LINE: เลือกโรงเรียน, ล้างคำค้นเดิม, เปิดมุมตรวจรายการของโรงเรียน, แสดงรายการ **ทั้งหมด** จากข้อมูลตารางเดิม
4. ข้อความ LINE แสดงชื่อโรงเรียน, จำนวนรายการตาม `venue-table` จริง, คำขอให้ตรวจรายการขาด/เกิน/ระดับชั้น และข้อจำกัดว่าไม่ใช่รายการสมัครที่รับรองแล้ว
5. แชร์ผ่าน `https://line.me/R/share?text=...` โดยใช้ anchor ที่อัปเดตตามโรงเรียน; มีปุ่มคัดลอกลิงก์สำรองพร้อมสถานะที่อ่านได้
6. CSS แยก; ขนาดปุ่มสัมผัสอย่างน้อย 44 px, focus-visible, light/dark, มือถือและ desktop; ไม่มีการผูกข้อมูลส่วนบุคคลหรือ secret
