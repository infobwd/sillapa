### นโยบายภาษาที่ต้องคงไว้

1. **ร่าง/วางแผน ≠ ประกาศยืนยัน** — ไม่ใช้คำว่า “เปิดแข่งขันแล้ว” หรือ “สมัครแล้ว” กับรายการที่ยังเป็นร่าง
2. **ส่งข้อมูลแล้ว ≠ เขตตรวจรับแล้ว** — ใช้คำว่า “เขตตรวจรับ” เฉพาะข้อมูลทางการ
3. **— ≠ 0** — ค่าว่างในผลการแข่งขันครั้งที่ 74 ยังไม่มีแหล่งยืนยัน ไม่ใช่ยอดศูนย์
4. **กรรมการครั้งที่ 73 ≠ แต่งตั้งครั้งที่ 74** — ห้ามย้ายชื่อกรรมการไปเป็นผู้ได้รับแต่งตั้งโดยอัตโนมัติ
5. **แผนในเครื่อง ≠ ข้อมูลส่วนกลาง** — ไม่มีการเขียนข้อมูลครู/นักเรียน/กรรมการไปยัง API ใหม่
6. **เปลี่ยนเฉพาะข้อความผู้ใช้** — เก็บ `activity_id`, `stage_scope`, `district`, `cluster`, `publication_state` และฟิลด์สัญญาข้อมูลภายในไว้ตามเดิม
7. **ห้ามตีความกิจกรรมครั้งที่ 70/73 เป็นข้อบังคับของครั้งที่ 74** — ชื่อระดับชั้นจากประวัติเป็นเพียงฐานวางแผน

## เกณฑ์ตรวจรับ Local-First

ใช้ Git/Node ใน VS Code เครื่องผู้ดูแล (ไม่มี GitHub Actions เพิ่ม):

```powershell
git fetch origin
git switch --detach origin/fix/ia1-ia6-plain-thai-ui-copy
git rev-parse HEAD
git status --short
node tests/ia2-registry.test.cjs
node tests/ia3-readiness.test.cjs
node tests/ia4-school-workspace.test.cjs
node tests/ia5-judge-venue.test.cjs
node tests/ia6-executive.test.cjs
node tests/ui-plain-thai-copy.test.cjs
git diff --check origin/main...HEAD
python -m http.server 8000
```

ทดลองเปิดหน้า `http://localhost:8000` โดยเริ่มที่ `#overview`, `#next`, `#prep`, `#readiness`, `#venue`, `#executive` และ `#archive`. ยืนยันว่า:

- คำบนมือถือ iPhone / iPad / Desktop ไม่ถูกตัดจนสื่อสารผิด; ยังใช้เมนูหกส่วน / bottom nav สี่ส่วนตาม IA-1
- ผู้ปกครอง ครู แอดมินกลุ่ม และผู้บริหารอ่านแล้วรู้ว่า **ข้อมูลนี้เป็นร่าง**, **ต้องทำอะไรต่อ**, **ที่มาคืออะไร**
- หน้า IA-2 ยังนับ 56 กลุ่มตามข้อมูลในร่างเดิม และไม่ทำให้ตัวเลขย้อนหลังเป็นตัวเลขรับรองปี 74
- การเปลี่ยนกลุ่ม ตัวกรอง ระดับการแข่งขัน ไฟล์ CSV เช็กลิสต์ และแผนกรรมการ/ห้องบนเครื่องยังทำงาน
- เลือกโรงเรียนอีกแห่งแล้วแผนไม่ปนกัน; เครื่องหมาย — ยังคงขึ้นเมื่อไม่มีข้อมูลรับรอง
- เนื้อหาที่แสดงเมื่อออฟไลน์อธิบายว่าข้อมูลอาจไม่ใช่ฉบับล่าสุด
- Service worker เปลี่ยนเป็น `sillapa-public-v9-ia6-20261015` เพื่อให้เว็บ/แอปตรวจพบไฟล์หน้าเว็บรุ่นใหม่
- การปรับไม่ได้เพิ่มการส่งรายชื่อ/ข้อมูลส่วนบุคคลออกจากเบราว์เซอร์
