## เป้าหมาย / Acceptance Criteria
1. ใช้ชื่อรายการย่อยภาษาไทยในตารางเกณฑ์ครั้งที่ 74 อย่างถูกต้องสำหรับ #7–8 และเก็บชื่อเก่าจากโรงเรียนไว้ค้นหา
2. รายการ #70–74 ทุกแถวมีชื่อและระดับชั้นตรง PDF ทางการ และเชื่อมลิงก์ PDF โดยไม่ลบข้อสงสัยเรื่องชั้นที่โรงเรียนเลือกใน #73
3. รายการเรียนรวมที่ **ทราบประเภทความบกพร่อง** ต้องไม่รวมกับรายการที่ **ยังไม่ระบุประเภท** ให้เหมือนเป็นคู่แข่งขันเดียวกัน
4. เก็บชื่อโรงเรียน ระดับชั้น และจำนวนรายการรายโรงเรียนเท่าเดิม ไม่เดาประเภทให้โรงเรียนบ้านหนองกระทุ่ม และไม่อ้างว่ามีการรับรองผู้สมัคร
5. คงการแจ้งเตือน 9 ประเด็นรอโรงเรียนบ้านหนองกระทุ่มยืนยัน และเพิ่ม #76 แยกต่างหาก
