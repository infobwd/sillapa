# Sillapa — ระบบสารสนเทศเพื่อเตรียมจัดการแข่งขันศิลปหัตถกรรมครั้งที่ 74

เว็บ **Progressive Web App (PWA)** สำหรับผู้จัดและโรงเรียน สพป.กาญจนบุรี เขต 4 ใช้วิเคราะห์ข้อมูลครั้งที่ 73 ร่วมกับรายการอ้างอิงครั้งที่ 70 เพื่อเตรียมกิจกรรม กรรมการ และแผนส่งแข่งขันครั้งที่ 74 **ไม่ใช่เว็บรายงานผลการแข่งขันครั้งที่ 74** ไม่ใช่ระบบรับสมัครหรือฐานข้อมูลกลางแบบเรียลไทม์ รองรับติดตั้งเป็นแอปและอ่าน snapshot ที่แคชไว้เมื่อออฟไลน์

## แผนพัฒนาระบบสารสนเทศเตรียมการแข่งขันครั้งที่ 74

การพัฒนาขั้นถัดไปต้อง **ออกแบบให้เป็นระบบสารสนเทศเพื่อเตรียมจัดการแข่งขัน ไม่ใช่เว็บรายงานผลการแข่งขันครั้งที่ 74** และไม่สร้างฐานข้อมูลรับสมัคร/ผลคะแนนคู่ขนานกับ `infobwd/AcademicCompetitionManager`

- **[Information Architecture & Data Contract Design Lock](docs/SILLAPA74_INFORMATION_ARCHITECTURE_DATA_CONTRACT_DESIGN_LOCK.md)** — *PROPOSED / รอผู้ดูแลตรวจรับ*: โครงสร้างระบบเป้าหมาย 6 ส่วน, เมนูมือถือ 4 รายการหลัก, มาตรฐานข้อมูลครั้งที่ 70/73/74, การยืนยันข้อมูล, คีย์เชื่อมโยง, ความปลอดภัย/PII และเกณฑ์ตัวชี้วัด
- **[Information Architecture Delivery Roadmap](docs/SILLAPA74_INFORMATION_ARCHITECTURE_ROADMAP.md)** — *PROPOSED*: ลำดับ IA-0 (เอกสารนี้) → IA-1 (หน้าแรก/เมนู) → IA-2 (ทะเบียนรายการ) → IA-3 (ผู้จัด/กลุ่มเครือข่าย) → IA-4 (โรงเรียน) → IA-5 (กรรมการ/สนาม) → IA-6 (วิเคราะห์ผู้บริหาร)
- [ข้อเสนอ Decision Hub เดิม](docs/SILLAPA74_DECISION_HUB_DESIGN_PROPOSAL.md) ยังใช้เป็นหลักฐานโจทย์ของผู้จัด/โรงเรียน แต่เอกสาร Design Lock ใหม่เป็นข้อเสนอเพื่อทบทวนร่วมกัน **ยังไม่ถือว่าอนุมัติพัฒนา Backend**
- **ขอบเขต PR เอกสาร:** ไม่แก้ `index.html`, JavaScript, Service Worker, กำหนดการแข่งขัน, ฐานข้อมูล, ข้อมูลครั้งที่ 73 หรือระบบรับสมัคร; ยังไม่เปลี่ยนหน้าเว็บจริงหลัง Merge จนกว่าจะมี PR โค้ด IA-1 และผ่านการตรวจรับ

## IA-1 — หน้าแรกและเมนูหลักสำหรับเตรียมการแข่งขันครั้งที่ 74

**สถานะ IA-1:** Merge PR #6 แล้ว (Commit `9266ebe`) · [IA-1 Implementation & Acceptance](docs/SILLAPA74_IA1_IMPLEMENTATION_ACCEPTANCE.md)

- หน้าแรกเปิดด้วย **ศูนย์ข้อมูลเตรียมจัดครั้งที่ 74** พร้อมทางลัดดูร่างรายการและเตรียมส่งโรงเรียน ก่อนสถิติย้อนหลัง
- แสดงจำนวนกิจกรรมใน **ร่าง** ครั้งที่ 74 จากข้อมูลร่างจริง และแสดง **—** เมื่อยังไม่มีข้อมูลยืนยันรายการรับสมัคร/กลุ่มส่งตัวแทน/กรรมการและสนาม ห้ามตีความว่าเป็นศูนย์
- เมนูหลัก **6 ส่วน**: ภาพรวมการเตรียมงาน / รายการแข่งขัน 74 / เตรียมแข่งขันของโรงเรียน / ความพร้อมผู้จัดและกลุ่มเครือข่าย / กรรมการและสนามแข่งขัน / คลังข้อมูลย้อนหลัง 70 และ 73
- มือถือและ iPad แนวตั้ง: Bottom Navigation **ภาพรวม / รายการ 74 / โรงเรียน / เพิ่มเติม**; เมนูเพิ่มเติมเปิดส่วนที่เหลือและทางเข้าข้อมูลย้อนหลัง บนจอคอมและ iPad แนวนอนกว้างเห็นเมนู 6 ส่วน
- **คงลิงก์เดิมครบ** `#overview`, `#reps`, `#groups`, `#schools`, `#acts`, `#judges`, `#next`, `#prep` แม้จะจัดการนำทางใหม่; แผนโรงเรียนใน `localStorage` ไม่ถูกแปลงเป็นใบสมัครจริง
- เพิ่มไฟล์ `ia1.css` สำหรับ layout และอัปเดต `sw.js` ให้แคชไฟล์ใหม่พร้อมเปลี่ยนหมายเลขรุ่น; ฟีเจอร์ Splash, Skeleton, ดึงลงรีเฟรช, PWA ติดตั้ง และ Offline ยังใช้ต่อ
- หน้า **ความพร้อมผู้จัด** กับ **กรรมการและสนาม** ใน IA-1 ยังเป็นหน้าวางโครงและสื่อสารสถานะ **ยังไม่เชื่อมข้อมูลยืนยัน**; จะเพิ่มข้อมูลจริงในขั้น IA-3/IA-5 หลังตรวจสอบแหล่งข้อมูลและความปลอดภัย

## IA-2 — ทะเบียนรายการแข่งขันครั้งที่ 74 (ข้อมูลร่างและอ้างอิง)

**สถานะ:** พัฒนาใน Branch `feat/ia2-activity-registry-v1` เพื่อเปิด PR ตรวจรับก่อน Merge · [IA-2 Acceptance](docs/SILLAPA74_IA2_REGISTRY_ACCEPTANCE.md)

- หน้า **รายการแข่งขัน 74** แสดงทะเบียนข้อมูล **56 กลุ่มกิจกรรมในร่าง** (17 หมวด) โดยเปิดดูข้อมูลอ้างอิงรายกิจกรรมย่อยและระดับชั้นจากครั้งที่ 70/73 ได้จริง
- **ครั้งที่ 70:** 25 กลุ่มที่จับคู่กับร่างได้ 63 รายการย่อยพร้อมรหัสต้นทางไม่ซ้ำและระดับชั้นทุกระดับที่มีในชุดข้อมูลนี้; **ครั้งที่ 73:** 29 กลุ่ม 83 ชื่อรายการย่อยย้อนหลัง; อีก **2 กลุ่มรอการตรวจสอบ** (กลุ่มนาฏศิลป์และกลุ่ม Soft Power)
- ค้นหารายการและกรอง **หมวดหมู่ / ระดับชั้นย้อนหลัง / ที่มาครั้งที่ 70–73 / สถานะ / ระดับกลุ่มหรือเขต**; ระดับกลุ่ม/เขตครั้งที่ 74 ที่ยังไม่มีข้อมูลยืนยันต้องแสดงว่า **ยังไม่ทราบ** ไม่สร้างรายการแข่งขันทางการปลอม
- ดาวน์โหลด **CSV ตามตัวกรอง** แยกรายการย่อยและระดับชั้นครบถ้วน พร้อมรหัสของแหล่งย้อนหลังและรหัสอ้างอิงร่างชั่วคราว แต่ **เว้นว่างรหัสรายการทางการครั้งที่ 74**
- การเปรียบเทียบครั้งที่ 73 ↔ ร่าง 74 เดิมยังอยู่ในส่วนขยายใต้ทะเบียน ไม่ลบข้อมูลประวัติใด ๆ
- **ข้อจำกัดสำคัญ:** รายการครั้งที่ 70 อ้างอิงคลังของ **สพป.ร้อยเอ็ด เขต 3** เพื่อช่วยเตรียมงาน ยังไม่เท่ากับกติกาที่ สพป.กาญจนบุรี เขต 4 รับรองสำหรับครั้งที่ 74; เว็บไซต์เป็น static snapshot ยังไม่มี API รับรองและไม่สามารถใช้สมัครแข่งขันจริง
- เพิ่ม `ia2-registry.js`, `ia2.css` และปรับเวอร์ชันแคชใน `sw.js` เพื่อรองรับ PWA/Offline ตามแนวทางเดิม โดยไม่แก้ระบบรับสมัคร `AcademicCompetitionManager`

## กำหนดการแข่งขันครั้งที่ 74 (เพื่อการวางแผน)

- **ภายใน 4 ธันวาคม 2569:** กลุ่มเครือข่ายส่งผลและรายชื่อทีมตัวแทนเข้าสู่ระดับเขต (ไม่ใช่วันแข่งขันระดับกลุ่ม)
- **ประมาณ 21–24 ธันวาคม 2569:** ช่วงที่คาดว่าจะจัดการแข่งขันระดับเขต (กำหนดเบื้องต้น; วัน/เวลา/สนามแยกรายกิจกรรมรอประกาศ)
- วันแข่งขันระดับกลุ่ม วันเปิด/ปิดสมัคร และกำหนดรายกิจกรรมอื่น ๆ ยังไม่ทราบ ห้ามอนุมาน

หน้าเว็บแสดงกำหนดการเดียวกันใน **ภาพรวม / เทียบครั้งที่ 73–74 / เตรียมแข่งขันครั้งที่ 74** โดยอ้าง HTML template เดียว เพื่อลดความคลาดเคลื่อนในการแก้ไข

**แนวทางยกระดับเป็นเว็บฐานข้อมูลสำหรับผู้จัดและผู้แข่งขัน:** [ข้อเสนอ Sillapa 74 Decision Hub](docs/SILLAPA74_DECISION_HUB_DESIGN_PROPOSAL.md). เอกสารเป็น `PROPOSED`; ยังไม่มีการเชื่อมฐานข้อมูลจริง/แก้ Backend ของระบบหลัก

## บทบาทของระบบ (Planning Intelligence ไม่ใช่ผลแข่งขันครั้งที่ 74)

**ชื่อ/วัตถุประสงค์:** ระบบสารสนเทศเพื่อเตรียมจัดการแข่งขันงานศิลปหัตถกรรมนักเรียน ครั้งที่ 74 สพป.กาญจนบุรี เขต 4 มีหน้าที่ช่วยผู้จัดและโรงเรียนวิเคราะห์ข้อมูลย้อนหลัง วางแผนกิจกรรม กรรมการ และความพร้อม **ไม่ใช่ระบบรายงานผลการแข่งขันครั้งที่ 74 ไม่ใช่ระบบรับสมัคร และไม่ใช่ประกาศที่ยืนยันระดับชั้นของครั้งที่ 74**

**การใช้ครั้งที่ 70 สำหรับกิจกรรมที่นำกลับมา:** ถ้าร่างครั้งที่ 74 เลือกใช้กิจกรรมจากครั้งที่ 70 ต้องนำมา **ครบทุกประเภท/ทุกรายการย่อย/ทุกระดับชั้น** ที่ปรากฏในรายการครั้งที่ 70 ที่ตรวจสอบ ไม่ตัดให้เหลือเพียงระดับชั้นเดียว และไม่อนุมานว่าครั้งที่ 74 เปิดรับสมัครแล้ว
- เก็บรายการอ้างอิง 25 กลุ่มกิจกรรม รวม **63 รายการย่อยตามระดับชั้น** ใน `round70-catalog.js` จากบัญชีรายการศิลปหัตถกรรมครั้งที่ 70 ที่เผยแพร่โดย สพป.ร้อยเอ็ด เขต 3: https://sillapa65.vichakan.net/sp-ret3/?cat=7&file=view_all&name=category
- รายการใหม่อีก 2 กลุ่ม (**กลุ่มนาฏศิลป์ และกลุ่ม Soft Power**) ยังไม่มีชื่อย่อยตรงตัวที่ยืนยันได้ จึงแสดง **รอตรวจสอบ** ไม่เติมระดับชั้นคาดเดา
- หน้า **73 vs 74** และ **เตรียม 74** แสดงรายการอ้างอิงตามระดับชั้นทั้งหมด รวมในไฟล์ CSV ที่ดาวน์โหลดได้ โดยติดป้ายว่าเป็นข้อมูลครั้งที่ 70 **ยังไม่ใช่เกณฑ์/รายการที่ประกาศครั้งที่ 74**
- รายการผลครั้งที่ 73 เป็น snapshot ย้อนหลัง ไม่เปลี่ยนแปลงข้อมูลผลการแข่งขันหรือคณะกรรมการเดิม

## การรีเฟรชด้วยท่าทางบนมือถือ

เมื่ออยู่ด้านบนสุดของหน้าเว็บ ให้ใช้นิ้ว **ดึงลง** จนเห็นข้อความ **“ปล่อยเพื่อรีเฟรชข้อมูล”** แล้วปล่อย ระบบจะขออัปเดต Service Worker แล้วโหลดหน้าใหม่ ขณะออนไลน์อ่าน HTML ล่าสุดก่อนแคช หากออฟไลน์อาจเห็นข้อมูลเดิมในแคช การดึงเพื่อรีเฟรช **ไม่ได้ซิงก์ฐานข้อมูลจริง** (เว็บนี้เป็น static snapshot)

ท่าทางนี้ไม่ทำงานขณะเลื่อนในโมดัล/Bottom Sheet หรือเริ่มสัมผัสจากปุ่ม/ช่องค้นหา และอาจแตกต่างตามระบบ iOS/Android ที่มี native pull-to-refresh อยู่แล้ว

## PWA — ติดตั้งลงหน้าจอหลัก (เวอร์ชันรอตรวจรับ)

ตัวเว็บมี Web App Manifest และ Service Worker รองรับติดตั้งจาก URL แบบ **HTTPS** (GitHub Pages) หรือ **localhost** เพื่อทดสอบในเครื่อง

**จากภายในหน้าเว็บ** จะมีแนะนำ **“ติดตั้ง Sillapa ไว้บนหน้าจอหลัก”** สำหรับมือถือ พร้อมปุ่ม **“ดูวิธีติดตั้ง”**; เมื่อรองรับ native install prompt ปุ่มจะเป็น **“ติดตั้งแอป”** และกดเพื่อขอการติดตั้งได้ทันที ผู้ใช้ปิดคำแนะนำได้ และกด **“ติดตั้งเป็นแอป”** ที่ส่วนท้ายเว็บเพื่อเปิดคำแนะนำอีกครั้ง

### วิธีติดตั้ง

- **iPhone/iPad:** เปิดเว็บไซต์ใน Safari (หรือเบราว์เซอร์ที่รองรับ Add to Home Screen) → แตะ **แชร์ (Share)** → **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)** → **เพิ่ม** หากไม่พบเมนูให้เลื่อนดูในรายการแชร์
- **Android (Chrome):** เปิดเว็บ → กด **“ติดตั้งแอป”** หากเบราว์เซอร์อนุญาต หรือเมนู **⋮ → ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก**
- **คอมพิวเตอร์ (Chrome/Edge):** ใช้ไอคอนติดตั้งที่แถบที่อยู่หรือเมนูเบราว์เซอร์ (ขึ้นกับการรองรับ)
- **หลังติดตั้ง:** เปิดจากไอคอน **Sillapa 74** ได้เหมือนแอป และปุ่มเชิญติดตั้งจะไม่รบกวนในโหมด standalone

| `icons/apple-touch-icon.png` | ไอคอนหน้าจอหลัก iPhone/iPad ขนาด 180 |
| `pwa.css`, `pwa.js` | หน้าตาติดตั้ง คำแนะนำตามอุปกรณ์ การตรวจเวอร์ชัน |
| `sw.js` | Service Worker เก็บไฟล์สาธารณะสำหรับออฟไลน์ และอ่าน HTML แบบ network-first |

**Offline:** ต้องเปิดเว็บสำเร็จขณะมีอินเทอร์เน็ตอย่างน้อยหนึ่งครั้งเพื่อบันทึกแคช หลังจากนั้นเข้าหน้า Dashboard ที่เคยโหลดได้โดยไม่ต่อเน็ต ข้อมูลใน `index.html` เป็น **snapshot** ไม่สด/ไม่ซิงก์กับฐานข้อมูล; Google Fonts อาจใช้ฟอนต์สำรองเมื่อออฟไลน์ แผนโรงเรียนใน `localStorage` ยังอยู่เฉพาะอุปกรณ์/เบราว์เซอร์นั้น

**Updates:** HTML ใช้ **network-first** เมื่อออนไลน์เพื่อลดปัญหาหน้าเก่าค้าง; หาก Service Worker เปลี่ยน จะมีข้อความ **“มีเวอร์ชันใหม่”** ให้ผู้ใช้กดรีโหลด เวลาปรับรายการ precache หรือไฟล์ UI ต้องเปลี่ยนค่า `CACHE_NAME` ใน `sw.js` (เพิ่มเวอร์ชัน) และตรวจการเผยแพร่ผ่าน GitHub Pages ให้เสร็จก่อน

**ขอบเขตความปลอดภัย:** Service Worker ดักเฉพาะคำขอ GET ภายใน path ของเว็บนี้ และแคชเฉพาะไฟล์สาธารณะ ไม่แคช API รับสมัคร/ข้อมูลส่วนบุคคล/บริการภายนอก; การติดตั้งไม่ได้ทำให้ข้อมูลแผนของทุกโรงเรียนรวมศูนย์

**เกณฑ์ทดสอบ:** [PWA Acceptance Checklist](docs/PWA_ACCEPTANCE.md) — ตรวจ Android, iPhone, desktop, Offline/Online, data freshness และการเปิด/ปิดคำแนะนำติดตั้งก่อน Merge

## การปรับ UX สำหรับมือถือ (Splash / Skeleton)

- **ลดการซูมด้วยนิ้ว:** `viewport` จำกัด pinch/double-tap zoom บนเบราว์เซอร์มือถือ รักษาการเลื่อนหน้าและปุ่มตามปกติ; ปรับ `input/select/textarea` เป็นอย่างน้อย 16px บนมือถือเพื่อไม่ให้ iPhone ซูมเมื่อโฟกัสช่องกรอก บางเบราว์เซอร์หรือฟีเจอร์ช่วยการเข้าถึงอาจยังอนุญาตให้ซูมได้
- **Splash Screen:** แสดงตอนเข้าเว็บครั้งแรกของการโหลดหน้าเว็บ พร้อมชื่อการแข่งขันและหน่วยงาน ปิดเมื่อเรนเดอร์ข้อมูลหลักครบ ไม่หน่วงเกินความจำเป็น (ขั้นต่ำประมาณ 0.4 วินาที ยกเว้นผู้ใช้ตั้งค่าลดการเคลื่อนไหว)
- **Fail-safe:** ถ้าเริ่มต้นหน้าเว็บผิดพลาด มีข้อความแจ้งและปุ่มโหลดใหม่หลัง 7 วินาที ไม่แสดงสปินเนอร์ตลอดไป
- **Skeleton:** มีโครงร่างโหลดสำหรับ 8 หน้า (`overview/reps/groups/schools/acts/judges/next/prep`) ใช้ `data-loading` และ `aria-busy`; ซ่อนเมื่อข้อมูลพร้อม ในเว็บ Static นี้ทุกหน้าสร้างจากข้อมูลในไฟล์ จึง **ไม่เพิ่มดีเลย์ปลอม** เมื่อสลับหน้าที่มีข้อมูลพร้อมแล้ว
- **ขอบเขต:** ยังคงข้อมูลการแข่งขันเดิมทุกแถว ไม่แตะ Backend หรือระบบรับสมัคร `AcademicCompetitionManager`

ดูเกณฑ์ตรวจสอบก่อน Merge ที่ [UI Loading Acceptance](docs/UI_LOADING_ACCEPTANCE.md)

## ขอบเขตข้อมูลและข้อจำกัด

- ข้อมูลสถิติและรายชื่อที่แสดงถูกฝังอยู่ในไฟล์ `index.html` เป็น **snapshot** ไม่ใช่ข้อมูลสดจากระบบรับสมัครหรือฐานข้อมูลการแข่งขัน
- ร่างรายการครั้งที่ 74 และเกณฑ์/ตัวเลขอ้างอิงใช้เพื่อประกอบการวางแผน **ต้องตรวจสอบกับประกาศทางการก่อนใช้งานจริง**
- **GitHub Pages ไม่มี Backend/Database ของแอปนี้:** แผนที่ผู้ใช้สร้างผ่านหน้าเว็บจะเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ได้ส่งแผนไปรวมทั้งเขต และไม่ใช่ระบบร่วมแก้ไขหลายโรงเรียน
- ฟีเจอร์ออนไลน์ที่อาศัยบริการเฉพาะแพลตฟอร์มต้นแบบจะไม่ทำงานบน GitHub Pages โดยไม่ได้พัฒนา Backend เพิ่ม
- Repository และ GitHub Pages เป็นสาธารณะ: หน้านี้มี **ชื่อกรรมการและโรงเรียนจากไฟล์ที่ได้รับ** ควรตรวจสอบสิทธิ์และความเหมาะสมก่อนเผยแพร่/ส่งต่อ และไม่ควรเพิ่มข้อมูลส่วนบุคคลที่ไม่จำเป็น
- Repo นี้แยกจาก `infobwd/AcademicCompetitionManager` โดยไม่แก้ข้อมูลผลการแข่งขันเดิม รายชื่อครู นักเรียน หรือระบบรับสมัครในโปรเจ็กต์นั้น

## ทดสอบในเครื่อง (Local-first)

เปิด `index.html` ด้วยเบราว์เซอร์ หรือเปิดจากโฟลเดอร์ Repository ด้วยคำสั่ง:

```bash
python -m http.server 8000
```

จากนั้นเปิด http://localhost:8000/ ควรทดสอบทั้งมือถือ แท็บเล็ต คอมพิวเตอร์ เมนูค้นหา ตัวกรอง การเปิดรายละเอียด การจัดแผนและการดาวน์โหลดไฟล์

**ไม่ต้องติดตั้ง npm และไม่ต้อง build:** หน้าเนื้อหาหลักยังอยู่ใน HTML เดียว ส่วน PWA เพิ่มไฟล์ static CSS/JS, manifest, ไอคอนและ Service Worker; ฟอนต์จาก Google Fonts ใช้ได้เมื่อเชื่อมต่ออินเทอร์เน็ต
